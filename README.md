# Δηλώσεις συμμετοχής στο δείπνο ΕΜΣΤΕ

Η ελληνική φόρμα καλύπτει τις συνελεύσεις της 19ης Δεκεμβρίου 2026 και της
15ης Μαΐου 2027. Ο πηγαίος κώδικας αποθηκεύεται στο GitHub. Η εφαρμογή Node.js
αποθηκεύει τις δηλώσεις σε ιδιωτική SQLite σε μόνιμο δίσκο.

## Εκτέλεση και δημοσίευση

Με Node.js 24, το `node server.mjs` ανοίγει τη φόρμα στη διεύθυνση
`http://localhost:3000`. Το `render.yaml` περιγράφει μία υπηρεσία Render με
μόνιμο δίσκο. Χρησιμοποιήστε ένα instance για τον δίσκο SQLite και ορίστε τις
παραμέτρους στο Render. Συνδέστε το repository ως Render Blueprint. Ο δημόσιος
σύνδεσμος είναι αυτός που εκδίδει το Render.

| Μεταβλητή | Τιμή |
| --- | --- |
| `DB_PATH` | `/var/data/dinner.sqlite` στο Render |
| `ENABLE_MAIL_WORKER` | `true` στην παραγωγή |
| `MAIL_FROM` | Διεύθυνση αποστολέα σε επαληθευμένο domain του Resend |
| `RESEND_API_KEY` | Κλειδί αποστολής από το Resend |
| `DEC_ORGANIZER_TO` | Παραλήπτης αναφοράς μετά από κάθε εγγραφή Δεκεμβρίου |
| `MAY_ORGANIZER_TO` | Παραλήπτης ειδοποίησης Μαΐου |
| `DAILY_TO` και `DAILY_BCC` | Παραλήπτες της πρωινής ενημέρωσης από το παλιό `DEC_FINAL_DAILY`, χωρισμένοι με κόμμα |
| `DAILY_START_DATE` | Πρώτη ημερομηνία ενεργοποίησης στη νέα εφαρμογή σε μορφή YYYY-MM-DD |

Η επιβεβαίωση αποστέλλεται αμέσως μετά την καταχώριση. Οι αποτυχημένες
απόπειρες παραμένουν σε ιδιωτική ουρά για επανάληψη έως 23 ώρες. Η αναφορά
Δεκεμβρίου αποστέλλεται μία φορά ανά ημέρα από τις 09:30 ώρα Ελλάδας,
από 20 Νοεμβρίου έως και 18 Δεκεμβρίου 2026. Αν η εφαρμογή ανοίξει αργότερα
την ίδια ημέρα, μπορεί να στείλει τότε. Ορίστε την ημερομηνία μετάβασης και
σταματήστε τον παλιό καθημερινό trigger κατά την ενεργοποίηση του νέου.

## Μεταφορά και εξαγωγή εγγραφών

Εκτελέστε με Python 3 και `openpyxl`, σε χώρο με πρόσβαση στο Excel.
Χρησιμοποιήστε τη νεότερη εξαγωγή κατά τη μετάβαση.

```sh
python import-xlsx.py "GRAND COMMUNICATIONS.xlsx" | node server.mjs import
node server.mjs export dec2026 > dec2026.csv
node server.mjs export may2027 > may2027.csv
```

Οι εντολές Node πρέπει να τρέξουν με το ίδιο `DB_PATH` που χρησιμοποιεί η
υπηρεσία. Για απομακρυσμένη εγκατάσταση μεταφέρετε την εισαγωγή με ιδιωτικό SSH
προς τη διεργασία εισαγωγής. Η εισαγωγή παραλείπει τα ήδη καταχωρισμένα
κινητά ανά συνέλευση και δεν στέλνει αναδρομικά email. Τα Excel, CSV,
αντίγραφα της βάσης και μεταβλητές παραγωγής αποθηκεύονται ιδιωτικά.
Η εξαγωγή υποστηρίζει και τις δύο συνελεύσεις.

Το αρχείο Excel δεν περιείχε καρτέλα `cover`. Η νέα εφαρμογή αποτρέπει
τη διπλή εγγραφή κατά την υποβολή και δεν διαθέτει αναζήτηση προσωπικού
μηνύματος με αριθμό κινητού.
